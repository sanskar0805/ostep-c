# OSTEP System Programming in C

This is a sequence of phases and programs and a implementation first system programming repository, designed to get understanding in how the OS works at its kernel level, its selection criteria, its scheduling processes, etc.
Go through the development process of this whole repository to gain understanding about the Linux system core.
